# Latex Suite Plugin Cheatsheet

> 该插件默认面向 physics 宏包风格公式输入。支持自行配置并更改。部分命令参考了 [obsidian-latex-suite](https://github.com/artisticat1/obsidian-latex-suite/ ) 项目。使用 Gemini 3.1 pro 辅助完成。
>
> 输出中带 `•` 的部分为光标占位符。在输入中按 `Tab` 键完成光标占位符的跳转，输入完成后继续按 `Tab` 可跳出命令块。
>
> 绝大多数命令执行自动展开操作，即输入后自动转化为输出文本。如不希望转化可使用 `Ctrl + Z` 撤销。
>
> 部分命令输入后需要按 `Tab` 展开。

## 1. 模式与结构

| 输入          | 输出      | 说明         |
| ------------- | --------- | ------------ |
| `mk` 正文输入 | `$...$`   | 切换行内公式 |
| `dm` 正文输入 | `$$...$$` | 块级公式     |

## 3. 希腊字母（@ 触发）

> 直接打出命令将自动加上 `\` 符号。如打出 `beta` 将自动转化为 `\beta` 。若多打了 `\` 会自动吸收。
>
> 后续直接输入字母将自动补充空格，如 `betaE` 转化为 `\beta E` 。

| 输入         | 输出          |
| ------------ | ------------- |
| `@a`         | `\alpha`      |
| `@b`         | `\beta`       |
| `@g`         | `\gamma`      |
| `@G`         | `\Gamma`      |
| `@d`         | `\delta`      |
| `@D`         | `\Delta`      |
| `@e`         | `\epsilon`    |
| `:e`         | `\varepsilon` |
| `@z`         | `\zeta`       |
| `@t`         | `\theta`      |
| `@T`         | `\Theta`      |
| `:t`         | `\vartheta`   |
| `@i`         | `\iota`       |
| `@k`         | `\kappa`      |
| `@l`         | `\lambda`     |
| `@L`         | `\Lambda`     |
| `@s`         | `\sigma`      |
| `@S`         | `\Sigma`      |
| `@u`         | `\upsilon`    |
| `@U`         | `\Upsilon`    |
| `@o` / `ome` | `\omega`      |
| `@O` / `Ome` | `\Omega`      |
| `:p`         | `\varphi`     |

## 5. 大型运算符

| 输入             | 输出                              |                              |
| ---------------- | --------------------------------- | ---------------------------- |
| `sum`            | `\sum`                            |                              |
| `ssum`           | `\sum_{ • = • }^{ • }`            |                              |
| `prod`           | `\prod`                           |                              |
| `pprod`          | `\prod_{ • = • }^{ • }`           |                              |
| `lim`            | `\lim_{ • \to • }`                |                              |
| `ddx`            | `\dd{x}`                          |                              |
| `ddt`            | `\dd{t}`                          |                              |
| `ddd`            | `\dd{ • }`                        |                              |
| `dv0`            | `\dv{ • }`                        | `pdv` 同理                   |
| `dv1`            | `\dv{ • }{ • }`                   | `pdv` 同理                   |
| `dv2`            | `\dv[2]{ • }{ • }`                | `pdv` 同理，输入数字表示阶数 |

| `oinf`           | `\int_{0}^{\infty} • \dd{•}`      |                              |

## 10. 环境

| 输入    | 输出                          | 说明         |
| ------- | ----------------------------- | ------------ |
| `align` | `\begin{align} • \end{align}` | 其余环境同理 |
| `mat(`  | `\pmqty( • )`                 |              |
| `mat[`  | `\bmqty[ • ]`                 |              |
| `mat|`  | `\mdet| • |`                  |              |

> 考虑到兼容性问题，也可换成 `\begin{matrix}` 环境。

### 环境内输入规则

| 按键            | 效果                       |
| --------------- | -------------------------- |
| `Tab`           | 键入对其符号 `&`           |
| `Enter`         | 插入换行符 `\\` 后换行     |
| `Ctrl + Enter`  | 跳转至下一行，直至跳出环境 |
| `Shift + Enter` | 不插入换行符换行           |
